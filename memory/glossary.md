## Work Terms
| Term | Meaning |
|------|---------|
| OT | ล่วงเวลา (overtime) — มีอัตรา 1 เท่า, 1.5 เท่า, 2 เท่า, 3 เท่า |
| ค่าเข้าเครื่อง | ค่าตอบแทนการใช้เครื่อง POS |
| ค่ากะ | ค่าตอบแทนพิเศษสำหรับกะดึก |
| เงินสดขาดเกิน | ส่วนต่างเงินสดใน POS ณ สิ้นกะ |
| Planogram | ผังการจัดเรียงสินค้าบนชั้นวาง |
